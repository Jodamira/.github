# Jodamira

**Quality of Service for network technologies.**

Jodamira develops tools that measure and explain how network connections actually perform — beyond simple speed tests. The first product is an Android app focused on network quality analysis, diagnostics, and understandable QoS assessment.

## Focus

- **Network quality measurement** – latency, jitter, packet loss, throughput, bufferbloat and related metrics
- **QoS assessment** – standardized, reproducible scoring independent of provider marketing claims
- **Understandable presentation** – results that help end users and professionals alike
- **Privacy-conscious design** – clear purpose limitation and data minimization from the start
